🛡️ Cloudflare Turnstile Setup Guide

Stop Bot Submissions on Your Forms

🎯 What This Guide Does

This guide will help you set up Cloudflare Turnstile CAPTCHA protection to prevent bots from submitting your contact forms.

Benefits:

  • ✅ Completely free (unlimited verifications)
  • ✅ Better privacy than Google reCAPTCHA
  • ✅ Faster and less intrusive for users
  • ✅ Works seamlessly with your Cloudflare account
  • ✅ No API keys needed (just site keys)

Time Required: 5-10 minutes

🚀 Step 1: Access Cloudflare Turnstile

1Log into Cloudflare

  1. Go to https://dash.cloudflare.com
  2. Log in with your Cloudflare account credentials
  3. You should see your domain: absolutepestservices.com

2Navigate to Turnstile

  1. In the left sidebar, look for "Turnstile"
  2. If you don't see it in the sidebar, click your Account name in the top-left
  3. Then find "Turnstile" in the products list
  4. Or go directly to: Cloudflare Turnstile Dashboard
📌 Note: Turnstile is account-level, not domain-level. It appears under your account, not under a specific domain.

🔑 Step 2: Create Turnstile Site

3Add a New Site

  1. Click "Add Site" or "Create Widget"
  2. Fill in the details:
    • Site Name: Absolute Pest Services (or any name you prefer)
    • Domain: absolutepestservices.com
    • Widget Mode: Select "Managed" (recommended)

Widget Mode Options:

  • Managed (Recommended): Cloudflare decides when to show a challenge based on visitor behavior
  • Non-Interactive: Never shows a challenge (invisible check)
  • Invisible: Always performs a check but never shows a challenge

Use "Managed" for best bot protection with good user experience.

4Configure Advanced Settings (Optional)

You can leave these at default, but here are the options:

  • Pre-Clearance Duration: How long a visitor can submit forms after passing (default: 15 minutes)
  • Security Level:
    • Low: More permissive (fewer false positives)
    • Medium: Balanced (recommended)
    • High: Strictest (may challenge more legitimate users)

Recommendation: Start with Medium security level and Managed mode.

5Get Your Site Keys

  1. Click "Create" to create your Turnstile site
  2. You'll now see two keys:
    • Site Key: Public key (used in your website frontend)
    • Secret Key: Private key (used in your backend for verification)
  3. IMPORTANT: Copy both keys and save them somewhere safe

✓ Keys Generated!

You should now have:

Site Key (Public): 0x4AAAAAAAxxxxxxxxxxxxx
Secret Key (Private): 0x4AAAAAAAxxxxxxxxxxxxx

🔧 Step 3: Add Keys to Your Website

6Add Site Key to Environment Variables

Your website needs the Site Key (public key) to display the CAPTCHA widget:

  1. In your Replit project, find the Secrets (environment variables)
  2. Add a new secret:
    • Key: VITE_TURNSTILE_SITE_KEY
    • Value: Paste your Site Key from Cloudflare
📌 Why VITE_ prefix?

Environment variables in React/Vite must be prefixed with VITE_ to be accessible in the frontend.

7Add Secret Key to Environment Variables

Your backend needs the Secret Key to verify CAPTCHA responses:

  1. In Replit Secrets, add another secret:
    • Key: TURNSTILE_SECRET_KEY
    • Value: Paste your Secret Key from Cloudflare

✓ Environment Variables Set!

You should now have these secrets in Replit:

  • VITE_TURNSTILE_SITE_KEY - For frontend widget
  • TURNSTILE_SECRET_KEY - For backend verification

✅ Step 4: Implementation Complete

🎉 Setup Complete!

Once you've added both keys to your Replit secrets, the CAPTCHA will be automatically enabled on all your forms:

  • ✅ Contact Form
  • ✅ Inspection Scheduling
  • ✅ Service Requests

The CAPTCHA widget will appear at the bottom of each form before the submit button.

🧪 Step 5: Test Your CAPTCHA

8Test Form Submission

  1. Visit your website: absolutepestservices.com
  2. Go to any form (contact, inspection, or service request)
  3. You should see the Cloudflare Turnstile widget
  4. Fill out the form and submit
  5. The CAPTCHA should automatically verify (unless suspicious activity detected)

What You'll See:

  • Normal Users: Small widget that auto-completes with a checkmark ✓
  • Suspicious Activity: May show an interactive challenge
  • Bots: Will be blocked from submitting the form

9Monitor in Cloudflare Dashboard

Track bot submissions and challenges:

  1. Go back to Cloudflare Dashboard → Turnstile
  2. Click on your "Absolute Pest Services" site
  3. View analytics:
    • Total verification requests
    • Pass rate
    • Challenge rate
    • Solve rate
✓ Analytics Available:

You can see in real-time how many bot attempts were blocked and how many legitimate users passed verification.

🔒 Security Best Practices

Keep Your Secret Key Safe:

  • ✅ Store in environment variables (Replit Secrets)
  • ✅ Never commit to version control
  • ✅ Never expose in frontend code
  • ✅ Only use in backend verification

Site Key is Public:

  • ✅ Safe to expose in frontend HTML/JavaScript
  • ✅ Visible to anyone viewing your website
  • ✅ Used to render the CAPTCHA widget

⚙️ Advanced Configuration

Adjust Security Settings

If you're getting too many challenges (or not enough):

  1. Go to Cloudflare Dashboard → Turnstile
  2. Click on your site
  3. Click "Settings"
  4. Adjust:
    • Widget Mode: Try "Non-Interactive" for smoother UX
    • Security Level: Increase if still getting bots, decrease if users complain
  5. Click "Save"
💡 Tip: Start with "Managed" mode at "Medium" security, then adjust based on your analytics.

🆘 Troubleshooting

Issue: CAPTCHA Widget Not Showing

Check:

  • Verify VITE_TURNSTILE_SITE_KEY is set in Replit Secrets
  • Make sure the key starts with 0x4
  • Restart your application after adding the secret
  • Check browser console for JavaScript errors

Issue: Form Submission Blocked Despite Passing CAPTCHA

Check:

  • Verify TURNSTILE_SECRET_KEY is set in Replit Secrets
  • Check backend logs for verification errors
  • Ensure domain in Cloudflare matches your actual domain

Issue: Too Many False Positives (Legitimate Users Blocked)

Solution:

  • Lower security level to "Low" in Cloudflare Turnstile settings
  • Change widget mode to "Non-Interactive"
  • Check analytics to see pass/fail rates

Issue: Still Getting Bot Submissions

Solution:

  • Increase security level to "High"
  • Verify backend is actually checking the CAPTCHA response
  • Check Turnstile analytics to see if bots are even attempting
  • Consider adding honeypot fields as additional protection

📊 Understanding Analytics

Key Metrics in Cloudflare Dashboard:

Metric What It Means
Verification Requests Total number of CAPTCHA checks attempted
Pass Rate Percentage of users who passed without challenge
Challenge Rate Percentage of users shown an interactive challenge
Solve Rate Percentage of challenged users who successfully solved
Blocked Number of bot submissions prevented

Ideal Metrics:

  • Pass Rate: 95%+ (most legitimate users pass instantly)
  • Challenge Rate: <5% (few users need interactive challenge)
  • Solve Rate: 90%+ (challenged users successfully complete)
